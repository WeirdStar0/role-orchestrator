# ADR 007：可信本地与可验证强隔离分层

状态：Accepted：工程安全默认
日期：2026-09-21

## 背景
Worktree/提示词/命令前缀不是操作系统沙箱，Windows 两种 CLI 能力不相同。

## 决策
Local Trusted 明示风险；Hardened 要求已验证文件/网络/进程边界；未知必需能力拒绝。

## 后果
不能为达成全自动而开启跳过所有权限；早期某些模式会明确不可用。

## 未采用方案
将权限 YAML 当作已经强制执行、或只 kill 顶层 PID 的方案不采用。

## 验证与重新评估
M0 按 CLI+OS 实测，强边界不达标就禁止对应功能声明。
