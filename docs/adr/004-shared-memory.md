# ADR 004：受控共享记忆代替原始会话复制

状态：Accepted：用户已确认
日期：2026-09-21

## 背景
不同 CLI 的原生 session 不同，直接共享聊天会增加隐私和上下文污染风险。

## 决策
项目/任务/角色/执行分层，Memory 提案类型授权、来源、revision 与 context manifest。

## 后果
共享数据更可追溯，但需要抽取、冲突和过期策略；未验证内容不变为全局规则。

## 未采用方案
全量 transcript 同步和跨项目默认共享不采用。

## 验证与重新评估
检索效果不足时可加向量检索，但不能取消证据和授权层。
