# ADR 009：开放本地核心与独立商业扩展

状态：Partially accepted：商业边界已确认，Apache-2.0 为候选
日期：2026-09-21

## 背景
当前个人使用并开源，后续向团队付费提供不同版本。

## 决策
完整本地核心开源；团队治理/协作/托管独立发布；许可候选发布前确认。

## 后果
保留核心功能和安全审计；不能假定对全部贡献拥有重许可权或可以共享个人订阅。

## 未采用方案
按角色/本地 DAG 收费锁和商业服务作为核心运行依赖不采用。

## 验证与重新评估
正式 LICENSE、版权主体、安全渠道与供应商使用条款核对是公开发布门禁。
