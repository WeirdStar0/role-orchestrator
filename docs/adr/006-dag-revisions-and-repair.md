# ADR 006：不可变执行定义与返工扩图

状态：Accepted：DAG 已确认，展开语义为工程默认
日期：2026-09-21

## 背景
用户要复杂 DAG 和反复修复，但图内回边将破坏无环调度。

## 决策
运行节点不原地更改；图通过 revision/CAS 变化；失败审查追加新修复/复审节点。

## 后果
需要定义后继失效；三轮审查含首次，三次尝试含首次；总体预算硬限制。

## 未采用方案
循环边和无限自动重试不采用。

## 验证与重新评估
任何新循环类型须以有界展开或新 run 表达，不能绕过预算。
