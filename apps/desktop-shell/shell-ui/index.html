role-orchestrator 桌面壳 — 构建占位页

本壳(product role-orchestrator-shell)的正式界面是本机 local-api 的回环页面 (http://127.0.0.1:<port>,由 role-orchestrator-local-api-serve --db <path> 子进程提供, 令牌经 per-user 0o600 文件由操作者粘贴,壳不经手)。

本目录仅是 Tauri build.frontendDist 的构建占位: tauri.conf.json 的 app.windows 为空数组,窗口由 Rust 代码在 serve 子进程就绪(HTTP 探测收到响应)后创建并锁定到回环 origin, 本占位页不会在运行时被加载。

里程碑路线见 docs/BACKLOG.md(M8-03a/b/c)与 reports/M8-03-desktop-shell-adr.md。
