## 本版亮点(M11「Desktop Product Experience」)

- **新产品 UI(/app)**:桌面壳默认加载 `apps/desktop-ui` renderer——首屏
  「今天想完成什么?」+一句话建任务;侧栏四入口(新任务/项目/历史/
  设置);内部 ID 默认隐藏;任务详情 Agent 时间线(依赖分代=轮内并行
  同排)+节点下钻(尝试/事件日志/Diff)。**旧工作台未删除**,完整保留于
  `/`(整表工作台/配置 JSON 全文编辑/高级观测台/令牌手动登录)。
- **会话令牌自动认证**(ADR 010):壳对 loopback 来源自动注入
  `Authorization`(内存中转、不落日志、令牌文件 ACL 不变、页面不可读
  令牌);纯浏览器/探测失败时手动令牌流原样保留。
- **首启零配置**:自动检测已安装的 Claude Code / Codex(只读,零进程
  执行/零提权)→ 一键生成推荐 AI 配置(协调/架构/评审→Claude Code、
  开发→Codex,可改;幂等——已配置时 409 拒绝、从不覆盖)→ 重启桌面
  应用生效(如实提示,不热重载)。
- **项目与任务产品流**:项目登记(绝对路径+四道 fail-closed 门,幂等)
  →四角色绑定(事务式写,一次保存全部生效或全部不变)→新任务向导
  (单节点一句话,或多节点「高级」折叠)→任务历史与详情时间线→
  审批卡/返工轮次/评审记录下钻/Diff。

  高级设置折叠 / 开发者模式折叠);JSON 全文编辑仍归旧工作台「配置」页

## 新 UI 首启流程(0.4.0 起的推荐路径)

1. **安装并启动**:安装 NSIS 包,启动桌面应用;壳自动拉起本地 serve
   并打开新产品 UI(`/app`)。
2. **检测与生成配置**:首页探测卡自动显示检测结果(Claude Code ✓ /
   Codex ✓,或如实列出未检测项);点击「生成推荐配置」一键写入默认
   profiles(推荐组合可改;双 CLI 均未检测到时如实给清单与手动配置
   指引,不会伪造)。**重启桌面应用后配置生效**(提示明示,不热重载)。
3. **登记项目**:在「项目」页(或新任务向导内嵌入口)登记一个 git 仓库
   的绝对路径;服务端依次校验绝对路径/存在/是目录/是 git 仓库,任何
   一步拒绝都不会写入任何内容;重复登记是幂等的。
4. **绑定团队**:为项目四个角色(协调/架构/开发/评审)各选一个已载入
   的 AI 配置;保存是一次事务,四个角色同时生效或同时不变;绑定后对该
   项目的新建任务立即生效。
5. **执行任务**:新任务页写一句话目标、选项目(可选展开「高级:多节点
   工作流」声明执行/集成/评审节点与依赖),「开始执行」;详情页时间线
   实时呈现各角色进度(3 秒轮询,终态自动停止),需要时在节点上下钻
   查看尝试/日志/Diff,审批卡就地决策。
6. **进阶**:JSON 全文配置、观测台(任务 DAG/执行事件/Context/Memory/
   原始 API)仍在旧工作台 `/` 的「配置」与「高级(观测台)」页;
   `/app/settings` 的开发者模式折叠区有其定位说明。

## unsupported(明确不支持)

- 多用户/多租户/云部署;非回环远程访问(API 仅 `127.0.0.1` + 令牌)。
- run 级取消生产面(v1 无 cancel 路由与 UI)。
- 自动模型切换、模型投票、fallback、临时切换账号规避配额;Workflow/
  Task/Node 层 Profile 覆盖。
- 跨项目记忆共享;每任务多于一个 integration 节点的编排(链式/并行
  集成将在后续版本支持)。
- 返工轮次达上限(hold)后的**产品内处置入口**(目前无任何 HTTP/UI 面,
  详情页如实标注;处置归维护者/后续版本);评审记录的问题分级(严重级)
  呈现(持久化无该字段,UI 如实降级)。
- 沙箱声明:Worktree 分离代码目录,**不是安全沙箱**;Local Trusted 模式
  仅用于用户明确信任的仓库(Trusted-only)。
