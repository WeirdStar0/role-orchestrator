## 本版亮点(M10「编排产品化」)

- 统一 RunDriver 与轮内并行派发(跨 run 仍 FIFO,四层并发约束不变)。
- 多节点 DAG 声明编排:`POST /api/v1/runs` 可选 `workflow`(≤64 节点;
  v1 每任务至多一个 integration 节点)。
- TaskRun `status`+`outcome` 双字段(迁移 018)与失败/阻塞徽标。
- Memory/Context 读侧注入(只读检索、top-5、4096 字节整条 drop、A36
  形状脱敏、fail-open);单节点 prompt 保持裸 objective 逐字。
- 任务创建零配置副作用(破坏性:移除 `profileId`,见 CHANGELOG 迁移
  说明——四角色绑定先经 `PUT /api/v1/projects/:id/role-bindings` 配置)。
- 文档大收口:README 按本口径重写;docs/API_AND_EVENTS.md、
  docs/ORCHESTRATION.md、docs/MEMORY_AND_CONTEXT.md 对齐实现。

## implemented(已实现、有测试与验收证据)

- 单机单用户本地产品闭环:安装包开箱、令牌流(壳不经手令牌)、profiles
  配置页、建任务、实时进度、审批卡、outcome 徽标、托盘常驻(Windows)。
- 四角色单 Profile 绑定与冻结快照;任务创建只读绑定;漂移门 409。
- 多节点 DAG 编排声明与单 run 轮内并行派发;跨 run FIFO。
- TaskRun status+outcome 双字段;状态词汇表不变。
- Memory/Context 读侧注入(决策①②形状)与预算/脱敏/fail-open。
- 执行与治理面:worktree 隔离、多父基线集成、固定 SHA 审查、受控动态
  扩图、一次性审批、重试分类与预算、恢复协议、事件 REST/WS、脱敏诊断
  导出、SQLite 迁移链 001..018、备份演练。
- 模型性能统计只读基础设施(**费用字段结构性 unknown**——CLI 自报价格
  不入契约,不展示任何价格数字)。
- 真实 CLI 适配:claude/codex 双方言协议适配器与 M8-01 受控联调冒烟
  (脱敏 fixtures 与矩阵记录)。
- 安装形态开箱证据(本机,v0.3.0 口径;第 4 轮审查返修后按实录表述,
  详见 reports/M10-06-BATCH.md §4.4/§9):静默安装、无环境变量启动、
  serve 进程链指向安装目录载荷、端口监听、无凭据 403、带凭据 API 200、
  旧库幂等迁移、强杀树杀清零;M10 面 API 实证——多节点 workflow 声明
  (末次迭代实录:首次 POST 202 建快照冻结 run→重绑→202;422 绑定引导
  流程属早前迭代,以用户库时间戳为证的跨迭代合并陈述)、双 profile 双
  凭据组轮内并行(executions 表实测:两节点同刻派发、约 15.6s 区间
  重叠)、outcome 双字段终态、零注入尾注形状(两个多节点 run 共 4/4)、
  单节点裸 objective 逐字平价、双 integration 节点 400 拒绝;七字段
  漂移门:行为由自动套件覆盖,安装面该步骤无留存 HTTP 凭据行(以用户
  库 profiles 表时间戳为旁证)。

## unsupported(明确不支持)

- 多用户/多租户/云部署;非回环远程访问(API 仅 `127.0.0.1` + 令牌)。
- run 级取消生产面(v1 无 cancel 路由与 UI)。
- 自动模型切换、模型投票、fallback、临时切换账号规避配额;Workflow/
  Task/Node 层 Profile 覆盖。
- 跨项目记忆共享;每任务多于一个 integration 节点的编排。
